# omarchy-yandex-music

Яндекс Музыка без официального клиента: «Моя волна» с выбором настроения, волна по любому треку, «Мне нравится», поиск. Управление — медиаклавишами, значком в баре и модалкой по центру экрана: очередь, перемотка, плей/пауза, лайки, компактный экран «Моя волна» с настроениями.

## Установка

```bash
git clone https://github.com/predmaxim/omarchy-yandex-music ~/Projects/omarchy-yandex-music
~/Projects/omarchy-yandex-music/install.sh
```

`install.sh` ставит пакеты через `yay` (`mpv`, `mpv-mpris`, `qrencode`, `python-hatchling` — его не хватает в PKGBUILD библиотеки, `python-yandex-music-api-git` — нужна 3.1+, в ней вход по коду устройства; если они уже есть — `sudo` не нужен), линкует `systemd/ymd.service` в `~/.config/systemd/user/` и плагин `plugin/` в `~/.config/omarchy/plugins/predmaxim.yandex-music`, включает и перезапускает `ymd`. Значок в центральной группе индикаторов копирует хук `patch_indicators` из `omarchy-dotfiles` (после него — `omarchy restart shell`).

## Вход

Откройте модалку (Super+Shift+Y, клик по значку или `omarchy-shell predmaxim.yandex-music toggle`): без токена там код устройства и QR со ссылкой. Подтвердите на телефоне — `ymd` сам опросит токен. Токен лежит в `~/.config/predmaxim.yandex-music/token` (права 0600, не в git). Протух — модалка снова предложит вход.

## Управление

| Что | Как |
|---|---|
| Открыть модалку | Super+Shift+Y (привязка в `hyprland.lua` из `omarchy-dotfiles`), левый клик по значку, `omarchy-shell predmaxim.yandex-music toggle` |
| Пауза / плей | правый клик по значку (пока есть звучащий трек), кнопка в шапке, медиаклавиши, Space из любой строки при пустом поле поиска, Enter сразу после открытия (курсор стоит на кнопке; ничего не играет — на первой строке) |
| Следующий / предыдущий | медиаклавиши (`playerctl -p mpv next` / `previous`), кнопки в шапке — и в волне, и в «Мне нравится» |
| Перемотка | ползунок под названием, Shift+← / Shift+→ — на 10 с; на строке перемотки «Моей волны» ← / → — на 10 с, с Shift — на 30 с |
| Лайк / дизлайк | Ctrl+L / Ctrl+D, кнопки в шапке |
| Включить трек | Enter или клик на строке; выбор вкладки («Волна», «Мне нравится») только показывает список и музыку не трогает, выбранная ещё раз — ничего не перезагружает |
| Подгрузить ещё | прокрутка к концу списка или ↓ на последней строке — по 20 треков |
| Волна по треку | → на строке, затем кнопка 󰐑 |
| Строки, вкладки | ↑ / ↓ по строкам: вкладки → кнопки шапки → список; на строке вкладок ← / → сразу переключает вкладку; наведение мыши двигает тот же курсор |
| Вкладка «Моя волна» | компактная карточка вместо шапки и списка; строки (подсвечиваются целиком): вкладки, настроение, перемотка, кнопки (дизлайк · ⏮ ⏯ ⏭ · лайк). ← / → внутри строки: настроение выбирается сразу и во время волны перезапускает её — один раз, через 0,4 с после последнего шага; Enter нажать кнопку. До старта волны — заглушка и ▶ на том же месте |
| Очистить поле, закрыть | Esc |

Значок горит, пока играет или стоит на паузе: 󰐊 — играет, 󰏤 — пауза, 󰝚 — ничего не играет; подсказка — «Исполнитель — трек».

Список в окне и очередь воспроизведения — разные вещи: можно листать волну или искать, а музыка идёт дальше по той очереди, откуда включён трек. Указатель 󰐊 виден, когда открыт тот же список. Шапка, обложка и ползунок показывают звучащий трек и меняются, только когда новый заиграл; кнопки и ползунок всегда на месте (без трека — неактивны). Между треками — затухание и нарастание по 3 с.

## Устройство

```
плагин (QML) ── сокет $XDG_RUNTIME_DIR/ymd.sock ── ymd (Python) ── mpv --idle (IPC-сокет)
                                                        │               └ mpv-mpris → медиаклавиши, playerctl
                                                        └ Яндекс Музыка API
```

- `ymd` — пользовательская служба: держит очередь, получает ссылки на потоки, шлёт обратную связь волне (`radioStarted`, `trackStarted`, `skip`, `trackFinished`, лайки) и рассылает состояние подписчикам сокета (по JSON-объекту на строку).
- `mpv` — дочерний процесс `ymd` (`--prefetch-playlist`, кэш в памяти), держит предыдущий, текущий и следующий трек; упал — `ymd` его перезапускает. `mpv-mpris` даёт MPRIS, поэтому медиаклавиши идут прямо в плеер.
- Плагин `predmaxim.yandex-music` (`plugin/`): значок и модалка по центру; разбор состояния — `Model.js`.

### Кэш

| Что | Где | Сколько |
|---|---|---|
| Ссылки на потоки | память `ymd` | 10 мин; протухла — запрос заново |
| Сыгранные треки из «Мне нравится» | `~/.cache/predmaxim.yandex-music/tracks/` | до 2 ГБ, старые удаляются первыми |
| Обложки (200 px), следующая — заранее | `~/.cache/predmaxim.yandex-music/covers/` | до 200 МБ |

Кэш можно удалить целиком — `ymd` скачает заново.

## Проверка

```bash
timeout 60 python -m pytest -q   # ymd: очередь, волна, сокет, кэш, mpv (заглушки API и mpv)
timeout 30 node plugin/test.js              # плагин: разбор состояния, переводы
journalctl --user -u ymd         # журнал службы
playerctl -p mpv status          # плеер виден по MPRIS
```
